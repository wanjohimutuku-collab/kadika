# WhatsApp templates for Kenya

Moved to [whatsapp-templates.md](whatsapp-templates.md), which covers Tanzania and Kenya. Kenya has its
own `kadisasa_card_ke` and `kadisasa_reminder_ke` (one `hosts` field, ADR 026); pledge,
contribution, memories and OTP share the Tanzanian templates, so set the `_KE` env vars to the same
names.
